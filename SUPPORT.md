# Getting help

Dura POS is not ready for live trading yet (see the [README](README.md)).
Until it is, these are the ways to get in touch.

| You want to | Do this |
|---|---|
| Report a bug, or ask for a feature | Open a GitHub issue using a template. Use fictional or redacted data only |
| Ask how something is designed | Check the [handbook](handbook/README.md) and [glossary](handbook/product/04-glossary.md) first, then open an issue |
| Report a security problem | Follow [SECURITY](SECURITY.md). Never use a public issue |
| Get help setting up a shop, migrating records, or a custom integration | That's paid consulting, offered by the maintainer. The app itself is always free |

**Never post these in an issue:**

- PINs;
- passwords;
- merchant keys;
- ZIMRA keys or certificates;
- Google tokens;
- real customer records.

Once the app ships, it will have a **Report a problem** screen. It attaches
redacted logs and gives you a reference number, so you don't need to write a
technical description.
