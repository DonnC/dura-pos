# Dura POS

Use AGENTS.md and handbook/engineering/00-engineering-contract.md as the active
project instructions. Apply the repository skills under .agents/skills.

The application is a Flutter/Pub workspace with Melos, Riverpod, Drift and a
small shared UI package. Fiscalisation is optional and deferred. The foundation
has no live sales, payments or Google sync yet. Historical notes and cdx
prototypes are references, not proof of implemented features.

Preserve owner-controlled records, local-first persistence and usable exports.
Use behaviour-first tests, meaningful changelog entries and the roadmap gates.
Read the handbook's file lifecycle and security policies before altering data.
No AI attribution, invented performance results or certification claims.
Commit only when asked. A local commit request does not authorise a push,
publication, external message, deployment or store upload.
