# Dura POS 0.1.0-dev.1 — foundation

Publication is disabled in release.json. This file prepares future versioned
release metadata; no tag, release or store upload has been created.

The Android shell demonstrates local preferences, reusable controls and private
rotating diagnostic logs with explicit support-ZIP sharing. There is no live
selling, Google synchronisation, cashier authentication, payment or fiscal feature.

Local database schema: 1, non-secret preferences only. No production business-file
or hub protocol migration is introduced. The selected logo is a design asset,
not yet a final launcher/store asset set.

Verification evidence and untested device conditions are listed in
handbook/engineering/08-foundation-validation.md. A future published release must
state its exact source commit, verified artifact checksums, signing/update
identity, platform requirements and migration limitations.
