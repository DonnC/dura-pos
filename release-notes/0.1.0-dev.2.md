# Dura POS 0.1.0-dev.2: records that balance

Publication is disabled in `release.json`. No tag, release or store upload has been
created.

## What changed

- The shop's records are double entry. `Payments`, the `Stock Ledger` and the `Money
  Ledger` name a debit account, a credit account and an amount, with no new tab.
- `Reports` has a trial balance and a balance sheet.
- Fewer tabs: `Summary` in `My Shop` moved into `Reports`, and `Fiscal Days`, `HS Codes`,
  `Quotes` and `Payment Callbacks` stay hidden until the feature is on.
- The phone has a durable outbox and an uploader. Nothing runs them yet, because the
  app has no selling screens.
- The hub refuses a used batch number with different events.

## Update and compatibility

| Version | Value |
|---|---|
| App | 0.1.0-dev.2, build 2 |
| Local database schema | 2, upgraded from 1 by adding the outbox tables |
| Workbook layout | 4 |
| Hub protocol | 1, with one new error code, `batch_reused` |

A hub on this version needs layout 4 workbooks, because it writes the new columns. No
real shop has data yet, so there is no workbook migration: test shops are rebuilt from
the new templates. Downgrading the app past database schema 2 is not supported.

## Verification and known limits

See the pull request for each change. A cash sale's records cover the pricing currency
with VAT at zero. Stock is held at cost including VAT, which an accountant should
confirm for a VAT-registered shop before a pilot.
